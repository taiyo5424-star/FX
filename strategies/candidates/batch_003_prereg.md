## C018: 米指標イベント後ドリフト(announcement drift)

- **市場構造仮説**: CPI/NFP/FOMC等の高インパクト指標のサプライズは即時に
  完全消化されず、初動方向へ数時間のドリフトが続く(学術文献の
  announcement drift / 注文フローの持続性)。これまでの全候補はイベント時間帯を
  除外して検証しており、**本候補はデータ上未使用の領域を対象とする**
  (多重検定の重複が小さい)。
- **対象イベント**: historical_events.json の cpi / nfp / fomc(固定・変更禁止)。
  BOJは発表時刻不定のため除外。
  - 発表時刻: CPI/NFP = 12:30 UTC(米夏時間)/ 13:30 UTC(冬)。
    FOMC = 18:00 UTC(夏)/ 19:00 UTC(冬)。米夏時間 = 3月第2日曜〜11月第1日曜。
- **シグナル**: 発表時刻T0直前の確定バー終値を基準に、T0+K分の確定バー終値までの
  変動が閾値以上なら、その方向へ次バー始値でエントリー。
- **パラメータ範囲(グリッド32通り ≤ 50)**:
  - K ∈ {15, 30} 分
  - 閾値 thr ∈ {10, 15} pips
  - SL ∈ {12, 18} pips
  - 保有 hold ∈ {4, 8} 時間(時間決済)
  - TP ∈ {なし, 1.5×SL}
- **介入日の扱い**: 主判定は介入ウィンドウ除外あり(従来候補と同条件)。
  除外なし(ライブ最悪ケース)を感度分析として併記。
- **想定サンプル**: 全期間イベント約110件 → 閾値通過でIS 60件前後。

## C019: 日次時系列モメンタム(スワップ算入・vol調整)

- **市場構造仮説**: USD/JPYの多日トレンドは政策金利差の漸進的織り込みと
  キャリーフローで持続する(time-series momentum文献)。既存候補は全て日中
  完結型で、多日保有・日足時間軸は未検証。
- **シグナル**: 日足(NYクローズ近似日、build_daily)終値で
  r = close[D] − close[D−L]。sign(r) が前日のsignと反転した日のみ、
  翌営業日の東京9:00以降最初のバーでエントリー(C009と同じ執行規約)。
- **パラメータ範囲(グリッド24通り ≤ 50)**:
  - ルックバック L ∈ {10, 20, 40} 営業日
  - SL ∈ {1.5, 2.5}×ATR14(20〜80pipsにクリップ)
  - 保有 hold ∈ {3, 5} 営業日(時間決済、TPなし)
  - 強度フィルタ f ∈ {0, 0.5}(|r| ≥ f×ATR14)
- **スワップ算入(必須・事前確定)**: 保有日数×(ロング +0.75pips/日、
  ショート −2.0pips/日)。根拠: 金利差約3.5%≒1.53pips/日。受取は半分に
  ヘアカット、支払いは3割増しの保守設定。ストレステストではさらに
  受取0・支払い×1.5を適用。
- **イベント除外**: エントリーバーのみ標準イベントマスク適用(保有中の
  イベント通過は許容=実運用と同じ)。
