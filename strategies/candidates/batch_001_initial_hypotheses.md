## C001: ゴトー日仲値ドル買いフロー
- セッション:Tokyo(9:00-9:55)
- 仮説:ゴトー日(5・10日)は輸入企業の実需ドル買いが仲値(9:55)に集中し、
  9時台にUSD/JPYが上昇しやすい構造的フローが存在する。
- エントリー概要:ゴトー日9:00頃買い、9:55仲値決定直前に決済。
- 主要リスク:既に広く知られたアノマリーで期待値が縮小している可能性。
  下落トレンド日は機能しない。祝日・月末は変則。
- フィルター案:上位足が下落トレンド中は見送り / イベント日除外
- OF: low(構造的説明明確) / AI: script(完全機械化可能)

## C002: 仲値天井フェード
- セッション:Tokyo(9:55-11:00)
- 仮説:仲値に向けたドル買い需要が9:55で消滅し、その後需給が反転して
  仲値前の上昇分の一部を戻す。C001の裏側。
- エントリー概要:ゴトー日で9時台に一定幅以上上昇した場合のみ、9:55直後に売り。
- 主要リスク:トレンド日に踏み上げられる。C001より不安定な可能性。
- OF: medium / AI: script

## C003: 東京レンジ→ロンドン初動ブレイク
- セッション:London(15:30-17:30 JST夏時間)
- 仮説:東京時間のレンジ(流動性薄)で溜まったオーダーが、ロンドン勢参入で
  一方向に解消される。東京レンジ幅が狭い日ほどブレイクの信頼度が高い。
- エントリー概要:東京時間(9:00-15:00)高値安値を基準に、ロンドン序盤の
  ブレイク方向へ追随。だまし対策:ブレイク後の押し戻し確認 or 時間フィルター。
- 主要リスク:だまし多発。欧州指標日は乱れる。
- OF: medium(だまし対策のパラメータ次第) / AI: script

## C004: NR7型ボラ収縮ブレイク
- セッション:London / New_York
- 仮説:日足レンジが7日間で最小(NR7)の翌日はボラ拡大が起きやすい
  (ボラティリティ・クラスタリングの裏面)。方向は前日までの上位足トレンドに従う。
- 主要リスク:方向予測が困難。両建てブレイクはコスト2倍。
- OF: medium / AI: script

## C005: 前日NY高値・安値の初回タッチ反発
- セッション:Tokyo / London
- 仮説:前日高値・安値は損切り・利食い・新規のオーダーが集積する参照価格で、
  「初回」タッチ時は反発しやすい(2回目以降はブレイクしやすい)。
- 条件案:レンジレジーム限定 / タッチ時の勢い(直前バーの伸び)で除外判定
- OF: medium / AI: script

## C006: 米指標後60分の落ち着き回帰
- セッション:New_York
- 仮説:高インパクト指標の初動オーバーシュート後、スプレッド正常化を待って
  (発表30-60分後)、初動と逆方向への部分回帰、または初動方向への
  秩序的継続のどちらかに分類できる。分類条件を特定できれば期待値化可能。
- 注意:イベントフィルター(前後30分禁止)と両立する設計。発表後30分以降のみ。
- OF: high(イベント個別性が強い) / AI: script判定+研究はFable5

## C007: ロンドンフィックス前後のフロー
- セッション:New_York(24:00 JST夏 / 25:00冬)
- 仮説:月末・四半期末のロンドンフィックスにリバランスフローが集中し、
  フィックスへ向かう方向とフィックス後の反転に偏りがある。
- 主要リスク:月末のみでサンプルが少ない。
- OF: high(サンプル不足) / AI: script

## C008: 週明け窓埋め
- セッション:週明け東京早朝は流動性薄のため**エントリーは9:00以降**
- 仮説:週末ギャップは投機的で、ファンダメンタル変化を伴わない小さな窓
  (例:20pips以下)は埋まりやすい。
- 主要リスク:大きな窓(事件・要人発言起因)は埋まらない。サンプル少(年50回未満)。
- OF: medium / AI: script

## C009: 日足5本線押し目買い(上位トレンド一致)
- セッション:任意(日足ベース、実行はLondon序盤)
- 仮説:明確な上昇トレンド中(例:20日線上向き+価格が上)の5日線タッチは、
  トレンドフォロワーの押し目買いが集まる。下落トレンドの戻り売りも対称。
- 保有:1-3日スイング。スワップ・週末ギャップをEVに算入必須。
- OF: low(古典的・構造説明可能) / AI: script

## C010: 米10年金利との短期乖離収斂
- セッション:New_York
- 仮説:USD/JPYは米金利(日米金利差)と高相関。日中の一時的乖離
  (金利横ばいでUSD/JPYだけ動く等)は収斂しやすい。
- 主要リスク:相関レジームが崩れる期間がある(介入期・リスクオフ期)。
  データ取得の仕組みが必要。
- OF: medium / AI: script(要金利データフィード)
