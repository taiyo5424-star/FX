# 松井証券 MATSUI FX 調査報告(2026-07-06、公開情報ベース)

調査主体:リサーチエージェント(Web公開情報)。最終確認責任はユーザー。
**要ユーザー確認事項は末尾に集約。**

## 結論(システム設計への影響)

1. **bot・スクリプトによる画面自動操作での発注は規程違反(禁止)**
   - FX取引規程 第9条:「取引サイト等以外のプログラム、ソフトウェア等を使用することはできません」(公式API許諾事業者経由を除く)
   - 第22条:違反と合理的に判断された場合、通知なく新規建て停止・数量制限
   - → 当システムの「発注はユーザー実行 or 公式自動売買機能への設定」方針は**必須**(docs/05と整合)
2. **公式の自動売買(リピート注文)機能あり・手数料無料・1通貨から**
   - 設定項目:売買方向 / 注文レンジ / 注文数量 / 注文値幅 / 益出し幅 / 運用停止ライン
   - 追証発生時は自動停止。逆指値スリッページ設定は変更不可
3. **個人向け公開APIなし**(FX APIは事業者向け限定、QUOREA FX等の第三者サービス経由のみ)
   - 第三者サービス利用は追加コスト・規約・安定性の検証が必要 → 当面は不採用

## バックテスト・EV計算への反映

- スプレッド:公表0.2銭(コアタイム)に対し、バックテスト保守値0.4pips(2倍)は妥当
- コアタイム外(早朝・週初・週末)は最大6.0銭 → **コアタイム外の新規エントリーは全戦略で禁止**とする
- 指標発表時のスプレッド拡大が公式に明記 → イベントフィルターの必然性を裏付け
- 自動売買手数料0円 → auto_trading_fee_R = 0(ただし実測スプレッドで再検証)
- 1通貨単位 → ポジションサイズの端数調整が自由(リスク2,500円制約を正確に実装可能)

## 要ユーザー確認(公開情報で未確認の項目)

1. 冬時間の日次処理時間帯の正確な時刻
2. 自動売買の注文レンジ等の設定可能範囲(最小/最大pips)→ 口座画面で確認
3. ご自身の口座のロスカット水準・レバレッジ設定値
4. **本調査の規程解釈の最終確認**(特に第9条・第22条の原文)
