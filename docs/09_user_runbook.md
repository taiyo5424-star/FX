## 運用モデルB: 判定=機械、発注=あなた(2026-07-19確立)

1. **毎朝8:15**にクラウドが判定。承認済み戦略のシグナル成立時のみ、
   スマホに発注案(BUY/SELL・数量・SL・TP・想定最大損失)がプッシュ通知される。
   通知が来ない日=シグナルなし=何もしない日(これが大半で正常)。
2. 通知が来たら: 発注案と注文確認画面を**1対1照合**して手動発注。
   数字を変えない(裁量の混入がこの運用の最大の敵)。
3. 画面に同席できる日は、ローカルで音アラート版も使える:
   `python scripts/live/signal_alert_engine.py`(docs/08_signal_alert_engine.md)。
   クラウド版と同じ安全ゲート・サイズ計算を共有。
4. 未承認戦略(現在のC009/C009v2)はshadow=ペーパー記録のみ。
   **APPROVED戦略が0件の間、発注指示の通知は来ない**(来たら異常。従わないこと)。
5. 取引した日は `python scripts/ops/daily_state.py trade-result --pnl 損益円` で記録。
